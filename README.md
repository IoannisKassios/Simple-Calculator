# 🧮 Simple Calculator - HTML Edition
A lightweight browser-based calculator built at 2am, for fun. Made with `HTML`, `CSS`, and `JavaScript`.

## 🎮 Description
A clean, functional calculator that runs entirely in the browser — no frameworks, no dependencies, just vanilla web tech. Built as a fun late-night project. The calculator features:

* Basic arithmetic operations (addition, subtraction, multiplication, division)
* Responsive button layout
* Real-time display of input and result
* Clear/reset functionality
* Minimal and clean UI design

A perfect starter project for learning front-end web development basics.

---

## 🚀 Getting Started

### Prerequisites

* Any modern web browser (Chrome, Firefox, Edge, etc.)
* No installation required

### Run the Calculator

1. Clone the repository:

```bash
git clone https://github.com/IoannisKassios/Simple-Calculator.git
cd Simple-Calculator
```

2. Open `index.html` in your browser:

```bash
open index.html
```

Or just double-click the file in your file explorer — it works instantly.
